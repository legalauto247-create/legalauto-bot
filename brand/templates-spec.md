# LegalAuto — Спека для генерации постов

## Общие правила бренда
- **Фон:** тёмный (графит/чёрный) для всех направлений, кроме «ДОКУМЕНТЫ» (бирюзовый/светлый).
- **Логотип:** щит «LA» + название суб-бренда (вверху-слева или по центру).
- **Шрифт:** жирный гротеск (заголовки CAPS), акцентные слова — цветом направления.
- **Подвал (всегда):** телефон `+7 938 515-24-29 (Эдуард)` + Telegram `@LegalAuto247` + слоган *«Ваш надёжный партнёр в мире автомобилей»*.
- **Иконки:** плоские, в цвете направления, в скруглённых карточках/чипах.

---

## 🟦 ДОКУМЕНТЫ (LEGAL AUTO)
- **Акцент:** бирюзовый / cyan (#1AA6C2) на светлом фоне.
- **Структура:**
  - **Сверху:** логотип + слоган «Помощь в оформлении документов на авто», волновой паттерн.
  - **Центр:** заголовок-вопрос («Нужно оформить авто без потери времени?») → буллеты-услуги (ромб-маркеры) → итоговая фраза-выгода.
  - **Низ:** авто (рендер на светлом), контактный блок.
- **Тон:** деловой, экспертный, успокаивающий («под ключ», «минимум участия»).

---

## 🟡 АВТО / STORE (LEGAL AUTO STORE)
- **Акцент:** золото/бронза (#C9A24B) на чёрном.
- **Структура:**
  - **Сверху:** круглый лого STORE + «ПРОДАЖА» + модель авто (CAPS, золото).
  - **Под заголовком:** чипы-характеристики (год / пробег / город) + плашка цены (золотой бейдж).
  - **Центр:** главное фото авто 3/4 + 3 мини-фото (зад, салон, перёд).
  - **Низ:** блок «ХАРАКТЕРИСТИКИ» (2 колонки иконок) → плашка «Полное сопровождение сделки» → контакты.
- **Тон:** премиум, статусный, конкретика по ТТХ и цене.

---

## ⚙️ ЗАПЧАСТИ / PARTS (LEGAL AUTO PARTS)
- **Акцент:** оранжево-золотой шестерёнчатый (#E8821E) на чёрном.
- **Структура:**
  - **Сверху:** лого-шестерёнка + «ЗАПЧАСТИ И КОМПЛЕКТУЮЩИЕ».
  - **Центр:** заголовок категории (двигатели/оптика/подвеска) + рендер детали справа, буллеты-чек слева (галочки).
  - **Низ:** CTA «Как заказать» (нумерованные шаги) / география доставки + контакты.
- **Тон:** практичный, про скорость и гарантию («быстрая доставка», «низкие пробеги», флаги стран).

---

## ⚖️ НОВОСТИ (LEGAL AUTO)
- **Акцент:** бирюзовый (#1AA6C2) на чёрном (как сторис основного бренда).
- **Структура:**
  - **Сверху:** ярлык-плашка «НОВОСТЬ / ВАЖНО / ПОЛЕЗНО ЗНАТЬ».
  - **Центр:** крупный заголовок темы (утильсбор, СБКТС, курсы валют) + краткий подзаголовок-вопрос; опционально таблица/иконка-молоток.
  - **Низ:** CTA «Читать в посте →» + лого/контакты.
- **Тон:** информационный, актуальный, «разбираем по делу», без продажи.
