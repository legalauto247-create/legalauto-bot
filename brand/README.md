# 🎨 LegalAuto — Бренд (единый источник стиля)

Здесь живёт визуальный и смысловой стиль LegalAuto. Из этой папки стиль берут **видео (Remotion), сайт/мини-апп и боты** — чтобы всё было в одном виде.

## Куда кидать наброски
**`brand/inbox/`** — складывай сюда ВСЁ сырьё для брендбука:
- скриншоты, фото логотипа, рефересы, которые нравятся
- цвета (хоть фоткой палитры), шрифты, примеры постов/роликов
- голосовые/текстовые заметки «хочу так», «не хочу так»
- PDF/картинки с мудбордов (refero, Pinterest, Figma-экспорт)

Имя файла — любое. Можно подписать: `logo_вариант2.png`, `цвета_нравится.jpg`, `тон_общения.txt`.

## Что происходит дальше
1. Ты накидал в `inbox/`.
2. Пишешь мне/Jarvis: «собери брендбук из набросков».
3. Я разбираю `inbox/`, вытаскиваю цвета/шрифты/тон и собираю:
   - **`brandbook.md`** — нормальный брендбук (логотип, палитра, шрифты, голос, правила)
   - **`tokens.json`** — машинные токены стиля (цвета/шрифты/радиусы), которые подключаются в видео и сайт автоматически
4. Дальше весь контент подгоняется под этот стиль.

## Файлы
- `inbox/` — твои наброски (вход)
- `brandbook.md` — собранный брендбук (живой документ)
- `tokens.json` — дизайн-токены (единый источник цветов/шрифтов для кода)

Связано со скиллом **brand-voice** (голос и контакты) — визуал + голос = полный бренд.
