## 🏗️ Архитектура платформы

### 1. Telegram-канал @LegalAutoParts24
- Автоматические посты каждые 30 минут
- AI пишет продающий текст для каждой запчасти (Claude)
- Фото запчасти из Яндекс.Облака
- Кнопка "Смотреть все запчасти" → открывает Mini App каталог

### 2. Mini App — Каталог запчастей
- URL: `https://legalauto247-create.github.io/legalauto-bot/catalog.html`
- Работает прямо в Telegram
- 1378 запчастей с фото и ценами
- Поиск по марке, модели, категории

### 3. Клиентский бот @LegalAutoAssist_bot
- Поиск запчастей по VIN-номеру
- Создание заявок
- AI-ответы на вопросы клиентов (Claude + Gemini)
- Автоответ при смене статуса заявки

### 4. Бот управления @LegalAutoAgentUprav_Bot  
- CRM: просмотр лидов, статусы, воронка продаж
- Аналитика: недельные отчёты
- Управление каталогом: добавить/обновить запчасть
- Уведомления о новых заявках

### 5. Backend (Google Apps Script + Google Sheets)
- База данных: 1378+ запчастей
- REST API для всех ботов
- Автопостинг через GAS триггеры
- Логирование всех действий

### 6. Node.js + Railway (AI-агенты)
- postAgent.js — AI-публикация в канал
- brainAgent.js — AI Orchestrator (Claude + Gemini)
- adminBot.js — управление и CRM
- clientBot.js — клиентский сервис
