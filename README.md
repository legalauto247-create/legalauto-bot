# LegalAuto Platform

**Запчасти и импорт авто — честно и быстро**

## Структура проекта

```
legalauto-core/
├── legalauto-node-bot/   ← Node.js боты на Railway (24/7)
│   ├── bots/             ← adminBot, clientBot, newsBot
│   ├── agents/           ← 20 AI агентов
│   └── website/          ← legalauto.online
├── auto_bot/             ← Python бот → @LegalAutoStore (24/7)
├── mini-app/             ← Telegram Mini App каталог
├── gas-scripts/          ← Google Apps Script (база данных)
├── LegalAuto_Brandbook.pdf
└── LegalAuto_Plans.pdf
```
