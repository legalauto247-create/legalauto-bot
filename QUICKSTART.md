## ⚠️ Если что-то не работает

### "OPENAI_API_KEY не задан"
```bash
# Проверить что .env существует
cat .env

# Убедиться что переменная есть
grep OPENAI_API_KEY .env
```

### "Bot is not responding"
```bash
# Проверить что токен правильный (без пробелов)
nano .env

# Перезагрузить бот
Ctrl+C
node index.js
```

### "Image generation зависает"
```bash

```

## 🎯 Что делает каждая функция

### 📊 Брифинг
- Рыночный анализ (тренды по сезонам)
- Возможности заработка
- Ведущие маржинальные запчасти
- Аналитика конкурентов

### 📝 Пост
- AI генерирует пост на базе темы
- Можно опубликовать в канал
- Синтез Claude + GPT-4o-mini

### 🎨 Изображение
- Генерирует изображение через gpt-image-2
- Примеры: "BMW тормозные колодки", "Акция на запчасти"
- Скачивает и отправляет в Telegram

### 📈 Рынок
- Анализирует рыночные вопросы
- Показывает конкурентов
- Ищет арбитражные возможности
- Расчет маржи по товарам

### 🚗 Авто-сервис
- СБКТС (сертификация безопасности)
- ЭПТС (электронный паспорт ТС)
- Импорт авто
- Перепродажа авто
- Таможенные пошлины

### 🧠 Память
- Запоминает факты о бизнесе
- Сохраняет важные решения
- История диалогов
- Долгосрочная память системы

### 📌 Заметки
- Добавлять задачи
- Отмечать выполненными
- Напоминания

## 🔧 Настройки

Команда `/settings` позволяет:
- Включить/выключить автопостинг
- Установить интервал постов
- Время утреннего брифинга
- Алерты на горячие лиды

## 📞 Техподдержка

Если что-то сломалось:

1. Проверить логи: `tail -100 logs/bot.log`
2. Перезагрузить бот: `Ctrl+C` → `node index.js`
3. Проверить .env файл на ошибки
4. Проверить интернет соединение
