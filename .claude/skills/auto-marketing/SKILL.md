# Auto-Marketing — продающий контент LegalAuto

Аудитории:
- **@LegalAutoStore** — покупатели авто под ключ (пригон). Боль: дорого/страшно/непонятно растаможить.
- **@LegalAutoParts24** — владельцы BMW/Geely/Li Auto ищут запчасть дешевле дилера.
- **@LegalAuto24** — 74 импортёра, возят сами. Нужны документы (СБКТС/ЭПТС/утильсбор) и свежие новости рынка. НЕ продавать им запчасти.

## Структура Reels/поста (AIDA, ≤15 сек)
1. **Хук (0–2 сек):** конкретика-крючок. «Audi A3L из Китая — 2 050 000 ₽ под ключ». Не «смотрите что у нас есть».
2. **Интерес:** 2–3 факта-чипа (год, пробег, двигатель). Только реальные.
3. **Желание:** что клиент получает — «под ключ, с документами, доставка 6–8 недель».
4. **CTA (один!):** авто → «Заказ → @LegalAuto247»; запчасти → «@LegalAutoAssist_bot»; документы → «Оформим СБКТС/ЭПТС → @LegalAuto247».

## Хуки, которые работают
- Цена-якорь: «X ₽ под ключ» в первой строке.
- Дефицит/свежесть: «только что приехала», «1 в наличии».
- Снятие боли: «растаможка и документы — наша забота».
- Сравнение: «у дилера дороже на N%».

## Правила
- Всегда применяй [[stop-slop]]: конкретика, без клише, ≤1 эмодзи/строка.
- Данные строго из объявления (см. [[context-engineering]]) — ноль выдумок.
- Контакты — только LegalAuto, чужие @/телефоны вырезать.
- Один пост = один объект = один оффер = один CTA.

## Метрики, на которые работаем
Заявки в бот/менеджеру, а не лайки. Каждый ролик должен явно вести к действию.
