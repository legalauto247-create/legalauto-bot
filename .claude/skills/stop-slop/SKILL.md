# Stop-Slop — планка качества против «генеричного AI»

Цель: ни один текст/дизайн LegalAuto не должен выглядеть как «сгенерировано нейронкой».

## Запрещено (мгновенный признак слопа)
- Клише и вода: «откройте для себя», «погрузитесь», «в современном мире», «не упустите», «качество на высоте», «индивидуальный подход», «команда профессионалов».
- Англицизмы-пустышки в кальке: «бесшовно», «раскройте потенциал», «уникальный опыт».
- Пустые прилагательные без факта: «отличный», «превосходный», «лучший» — заменить на цифру/факт.
- Эмодзи-спам (>1 на строку), восклицательные цепочки «!!!».
- Симметричные «маркетинговые» списки из 3 одинаковых пунктов ради красоты.
- Выдуманные характеристики, которых нет в источнике (год, пробег, цена) — НИКОГДА.

## Обязательно
- Конкретика вместо оценок: не «недорого», а «2 050 000 ₽ под ключ». Не «быстро», а «доставка 6–8 недель».
- Один чёткий оффер и один CTA на единицу контента.
- Живой человеческий тон автоэксперта-друга, короткие фразы.
- Каждое утверждение проверяемо из данных объявления.
- Числа форматируем по-русски: разряды пробелом, ₽ после числа («2 050 000 ₽»).

## Чек перед публикацией
1. Убери первую и последнюю «вводную» фразу — текст стал хуже? Если нет — она была слопом.
2. Каждое прилагательное → есть факт за ним? Нет — режь.
3. Прочитал бы это живой перекуп/импортёр без испанского стыда? Нет — переписать.

Если контент не проходит чек — переписать, не публиковать.
